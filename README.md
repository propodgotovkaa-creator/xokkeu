# Хоккей. Где спрятался звук Ш?

Готовая браузерная логопедическая игра: 13 предметных карточек, три ворот, плавное прицеливание, удар, отскок, звук и кубок в финале. Все иллюстрации — отдельные растровые WebP, включая младенца для слова «малыш». Сторонних сервисов, аналитики и сетевых библиотек нет.

## Запуск

Открывайте игру через HTTP, а не двойным нажатием на HTML: JavaScript использует ES-модули.

```sh
npm start
# http://127.0.0.1:4173
npm test
```

Node.js нужен только для локального сервера и тестов. На хостинге достаточно файлов `index.html`, `style.css`, `game.js`, `model.js`, папок `assets/` и `audio/`.

## GitHub Pages и Genially

В репозитории: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. После окончания публикации адрес игры:

`https://propodgotovkaa-creator.github.io/xokkeu/`

В Genially добавьте встраиваемый веб-контент:

```html
<iframe src="https://propodgotovkaa-creator.github.io/xokkeu/"
  title="Хоккей. Где спрятался звук Ш?"
  width="960" height="540" style="border:0;aspect-ratio:16/9"
  allow="autoplay; fullscreen" allowfullscreen></iframe>
```

Сцена масштабируется в пропорции 16:9 без прокрутки. В вертикальном окне остаются поля; для телефона удобнее горизонтальная ориентация. Аудио включается только после действия игрока, как требуют браузеры. Если встраивающая платформа применяет sandbox, ему нужны `allow-scripts` и `allow-same-origin` для загрузки модулей и звуков.

## Управление и механика

Движение мыши или пальца по льду непрерывно поворачивает клюшку. Щелчок левой кнопкой по льду, воротам или шайбе запускает удар. На сенсорном экране направление выбирается движением пальца, удар выполняется при отпускании. Стрелки клавиатуры меняют направление, пробел запускает удар. Отдельной кнопки удара нет. Прицел фиксируется на время удара. Вне проёма ворот удар считается промахом.

Верный ответ отправляет шайбу в ворота. При неверном ответе шайба поднимается и попадает в перекладину выбранных ворот, затем возвращается: проекция траектории на лёд всегда соответствует прицелу. Ошибка не меняет карточку и не раскрывает правильные ворота. Угаданные слова исключаются до следующей игры.

Анимация зависит от прошедшего времени, сглаживание прицела — экспоненциальное. Клюшка показана рукоятью вверх. Крюк делает боковой замах, ускоряется к шайбе, касается её через 340 мс и продолжает движение после удара. Шайба остаётся неподвижной до контакта. При щелчке фиксируется точное направление курсора, а клюшка плавно доворачивается во время замаха. Все основные художественные объекты загружаются до старта. Повторные удары блокируются состояниями игры.

## Проверки

`npm test` проверяет категории 13 слов, три направления, непрерывность прицела, совпадение наземной траектории и прицела, попадание в перекладину и состав перемешанной колоды.

Для браузерных проверок нужен Playwright и Chrome:

```sh
CHROME_PATH="/path/to/chrome" node tests/browser.cjs
```

Браузерный сценарий проходит все 13 карточек, ошибочный ответ, блокировку повторного удара, финал, перезапуск, управление касанием, клавиатуру и отсутствие прокрутки. Запускать после локального сервера.

## Графика и звук

`assets/` — 19 оригинальных иллюстраций, созданных встроенным ImageGen и оптимизированных в WebP с сохранением прозрачности. Художественное задание сохранено в `ART-PROMPTS.md`. CSS применяется к интерфейсу, трансформациям и разрешённой линией прицеливания; игровые объекты не рисуются CSS/SVG/Canvas.

`audio/` — пять отдельных оригинальных PCM WAV: удар, скольжение, штанга, гол, финал. Их воспроизводимый синтез — `scripts/audio.cjs`. Громкость ограничена, звук отключается кнопкой вверху.
